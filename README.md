# BitCrusher: An Affordable, Open Source, Electromagnetic Fault Injection Platform
_NOTE: This repository is still under construciton_

Security researchers need attainable, effective tooling to secure computing infrastructure. Tools for hardware security research have been
getting cheaper and more effective over recent years, but EMFI tooling has been left behind. The goal of BitCrusher is to fix this.

## State of BitCrusher
The BitCrusher project was started as an undergraduate senior project in September 2025. Beginning April 2026, project efforts will shift
towards pushing BitCrusher beyond a proof of concept, with the ultimate goal of being a stable, user friendly, drop in replacement for 
existing state of the art EMFI tooling.
